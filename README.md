# BOSS 智能投递助手

一个基于 Electron 的求职投递辅助工具。支持 **BOSS 直聘** 的批量打招呼，附带职位筛选、薪资过滤、投递日志、失败自动熔断。

---

## ⚠️ 先说风险，看完再决定用不用

**这个工具会让你的账号被平台风控。**

这不是危言耸听。开发过程中实测：

- BOSS 直聘服务端每日打招呼有硬上限（实测 **150 次/天**，全渠道计数，包含手动操作）
- 智联招聘在单日高频投递后直接**账号异常**，要求实名认证才能恢复
- 平台的风控看的是「行为模式」不是「单次点击」——每天的投递总量、间隔规律性、浏览停留时长都在模型里

**用它的代价：账号可能被限制投递、要求认证、甚至封禁。**

如果你的账号很重要（比如已经在和 HR 沟通中），别用。新号、小号、或者不介意风险的情况再用。

**本项目仅供技术学习与研究。使用产生的一切后果由使用者自行承担。**

## 功能

| 能力 | 说明 |
|---|---|
| 职位扫描 | 读取当前搜索结果页的所有职位卡片，提取标题、公司、薪资、地区、标签 |
| 智能筛选 | 按薪资下限、排除词（如「外包」「驻场」）、排除公司过滤 |
| 薪资解析 | 自动把「1.1-1.4万」「5000-7000元」「6-10K·14薪」统一换算成 K/月 |
| 批量投递 | 设定数量后自动逐个点击「立即沟通」，间隔随机 6-12 秒 |
| 防误投 | 投递前校验「右侧详情区的职位名 == 目标职位名」，不一致立即中止 |
| 防重复 | 记录已投职位 ID，重新扫描也不会重复投 |
| 自动熔断 | 遇到风控提示、人机验证、未登录、次数上限，立刻停止批量 |
| 运行日志 | 每一步都有时间戳记录，同时写入日志文件 |
| 进度球 | 右下角悬浮球显示投递进度，点一下立即停止 |

## 快速开始

### 方式一：直接用打包好的 exe（推荐给非开发者）

**直接下载：[BossAuto-1.0.0-win-x64.exe](https://github.com/huangyiyang1104-cloud/boss_auto/releases/download/v1.0.0/BossAuto-1.0.0-win-x64.exe)**（105 MB）

1. 下载后双击运行（首次启动需要 5-10 秒解压，属正常）
2. 右侧窗口扫码登录 BOSS 直聘
3. 搜索你要的职位（比如「Java 南昌」）
4. 点左侧「重新扫描」
5. 配置筛选规则 → 再扫一次 → 设定数量 → 点「开始投递」

也可以到 [Releases](../../releases) 页面查看所有版本。

### 方式二：从源码运行（开发者）

```bash
git clone https://github.com/huangyiyang1104-cloud/boss_auto.git
cd boss_auto
npm install
npm start
```

Windows 用户也可以直接双击 `start.bat`。

## 技术要点

### 为什么用 webview 而不是普通浏览器

Electron 的 `<webview>` 允许在页面里执行脚本、合成鼠标事件，同时保持登录态持久化（`partition="persist:boss"`）。这是实现「自动点击」的基础。

### 为什么投递前要校验职位名

BOSS 的「立即沟通」按钮在右侧详情区，不在卡片上。程序必须先点卡片让详情切换过去，再点按钮。

如果详情还没切换完就点按钮，会投给上一个职位的 HR——这是真实发生过的事故。所以每次投递前都要确认右侧标题和目标职位一致，不一致就中止。

### 为什么薪资要读接口

BOSS 把页面上的薪资数字用私有字体（PUA 字符）混淆了。页面上你看到的是 `15-20K`，DOM 里存的是一串私有区字符，用正常字体渲染会变成 `0-00K`。

只能拦 BOSS 自己的 XHR 响应，从 JSON 里的 `salaryDesc` 字段拿明文。

**技术细节**：Electron 的 preload 默认跑在「隔离世界」，那里的 `window.fetch` 和页面用的不是同一个对象，直接 hook 完全无效。必须用 `webFrame.executeJavaScript` 把钩子注入「主世界」，再用 `postMessage` 回传。

### 为什么要拦截导航

BOSS 点「立即沟通」成功后，会执行 `window.location.href = "/web/geek/chat?id=..."` 跳转到聊天页。

这一跳，职位列表的 DOM 全没了，后续投递全部作废。

必须在主进程监听 `will-navigate` 并 `preventDefault()`。注意：`<webview>` 标签上的 `will-navigate` 是无效的，必须拿到主进程的 guest `webContents` 才能拦。

## 已知限制

- 只适配 BOSS 直聘，智联招聘版本在另一个分支/仓库
- 平台改版会导致选择器失效，需要用 `probe.bat` 重新导出结构校准
- 便携版每次启动都要解压，冷启动慢
- 没有自动回复 HR 消息的功能
